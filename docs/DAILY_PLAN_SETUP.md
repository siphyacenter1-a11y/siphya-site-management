# แผนประจำวัน — รถเข้า-ออก (FM-GM-01-07) / เครื่องจักร (FM-GM-01-03)

หน้า `/daily-plan` · ใช้ได้กับบัญชี **ธุรการ (staff)** และ **admin** (บัญชีผู้ดูแลพื้นที่/ลงนามอย่างเดียวเข้าไม่ได้)

## ติดตั้ง
```
node scripts/migrate_daily_plan.js     # สร้างตาราง dplan_* (รันซ้ำได้ ไม่ลบข้อมูล)
```
ไม่ต้องติดตั้ง package เพิ่ม · พิมพ์ฟอร์มใช้ปุ่ม "พิมพ์ฟอร์ม" ของเบราว์เซอร์ (A4 แนวนอน) ไม่ใช้ Chrome ฝั่ง server

## ตาราง
| ตาราง | เก็บอะไร |
|---|---|
| `dplan_resources` | รายชื่อรถ/เครื่องจักรของแต่ละโครงการ (แถวในแบบฟอร์ม) — เอาออก = ปิดใช้ ไม่ลบ |
| `dplan_plans` | แผน 1 ใบ = โครงการ × วัน × ฟอร์ม · เวลาที่ส่ง · ผลตรวจความครบถ้วน ณ ตอนส่ง · ไม่นับ KPI |
| `dplan_items` | รายการในแผน (รถ/เครื่อง × ช่วงเวลา × งาน × จุดกอง/ผู้ขอใช้) · `added_after` = เพิ่มหลังส่ง |

## การใช้งาน
1. แท็บ **ตั้งค่ารายชื่อ**: เลือกฟอร์ม + โครงการ → "ใช้รายชื่อตั้งต้นจากแบบฟอร์ม" → แก้ให้ตรงโครงการ → บันทึก
2. แท็บ **กรอกแผน**: เลือกวันที่ (ค่าเริ่มต้น = วันทำงานถัดไป) → เพิ่มแถว หรือ "คัดลอกจากแผนก่อน" → บันทึกร่าง → **ส่งแผน**
   - เครื่องจักร: 1 ใบ = ช่วง OT 17:00 น.– ของ "วันที่ช่วง OT" (ค่าเริ่มต้น = วันทำงานก่อนหน้า) + 07:00–17:00 ของวันที่ของแผน
3. แท็บ **KPI**: ดูรายเดือน/รายโครงการ + แผนที่ไม่ครบ + ข้อมูลที่ขาดบ่อย

## KPI
**KPI = (จำนวนแผนที่ข้อมูลครบถ้วน ÷ จำนวนแผนทั้งหมดที่จัดทำ) × 100** — แยก 01-07 กับ 01-03
- "จัดทำ" = กดส่งแผนแล้ว (ร่างไม่นับ) · แผนที่ติ๊ก **ไม่นับ** (ผู้ขอแจ้งหลัง 16:00 / ผู้ขอไม่ให้ข้อมูล) ไม่อยู่ในตัวหาร
- ระบบตรวจความครบถ้วน **ตอนกดส่งครั้งแรก** แล้วเก็บผลไว้ — แก้ไขหรือเพิ่มรถด่วนทีหลังไม่เปลี่ยนผล (แถวที่เพิ่มหลังส่งมีป้าย "เพิ่มหลังส่งแผน")
- ส่งได้แม้ข้อมูลไม่ครบ (ช่องที่ขาดเป็นสีแดง) — แผนนั้นนับเป็น "ไม่สมบูรณ์"
- รถ (01-07): ทุกแถวต้องมี ทะเบียนรถ · ประเภทรถ · จุดกอง/จุดลงของ · เวลา
- เครื่องจักร (01-03): ทุกแถวต้องมี เครื่องจักร · ช่วงเวลา · งานที่ทำ · ผู้ขอใช้ (กลุ่มที่มีคำว่า "ลิฟท์" ไม่บังคับผู้ขอใช้ ตามแบบฟอร์ม)
- เวลาที่ส่งเทียบกำหนด 16:00 น. ของวันทำงานก่อนวันแผน (เครื่องจักร = วันที่ช่วง OT) แสดงประกอบ ไม่อยู่ในสูตร
  วันทำงาน = จันทร์–เสาร์ ไม่รวมวันหยุดในตาราง `transport_holidays` ของระบบขนส่ง
