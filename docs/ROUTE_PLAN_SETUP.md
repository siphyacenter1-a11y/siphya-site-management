# บันทึกการเปลี่ยนแผนเดินรถ (`/route-plan`)

ใช้แทนฟอร์มขอจองรถเดิม (`/route` ยังเปิดได้ แต่การ์ดใน /admin ชี้มาหน้านี้แล้ว) · **ใช้ได้เฉพาะบัญชี admin**

## ติดตั้ง
```bash
node scripts/migrate_route_plan.js   # สร้างตาราง rplan_* (รันซ้ำได้ ไม่ลบข้อมูล)
```
ไฟล์ที่อัปโหลดเก็บที่ `storage/route-plan/<วันจันทร์ของสัปดาห์>/` (PDF แต่ละ Revise + โฟลเดอร์ `att/` สำหรับรูปใบแจ้ง) — ต้องสำรองพร้อม `storage/` เดิม

## ใช้งาน
1. ได้ PDF "แผนเดินรถประจำสัปดาห์ (บริษัทฯ)" จากศูนย์สระบุรี → อัปโหลด (เลือกหลายไฟล์ได้)
   - เลข Revise อ่านจากชื่อไฟล์: `...Revise_05.11.2026.pdf` = 0 (ฉบับแรก), `...Revise_3_06.11.2026.pdf` = 3 · แก้ได้ก่อนกดอัปโหลด
   - อัปโหลดเลขเดิมซ้ำ = แทนที่ · อัปโหลดสลับลำดับได้ (คำนวณใหม่ทั้งสัปดาห์ทุกครั้ง)
2. ระบบเทียบแต่ละ Revise กับฉบับก่อนหน้า → รายการ **เพิ่ม / ยกเลิก / ย้ายวัน / สลับคัน-เที่ยว**
3. เลือกสาเหตุ + แนบรูปใบแจ้งยกเลิก/จองด่วน + หมายเหตุ (บันทึกทันทีเมื่อเปลี่ยน)
4. แท็บ "รายงาน": % ผิดแผนรายสัปดาห์ แยก BU / โครงการ / ผู้จอง / สาเหตุ

## กติกาการนับ (ค่าที่ระบบเดา แก้ได้ทุกรายการด้วยช่อง "นับ")
- นับเฉพาะงานขนส่ง (`ต้นทาง - ปลายทาง, วัสดุ, ผู้จอง`) ไม่นับเที่ยว "ลง..." และเฉพาะวัน จ.–อา. ของสัปดาห์ (ศ.–อา. ของสัปดาห์ก่อนที่ติดมาในไฟล์ไม่นับ)
- ไม่นับ: สลับคัน/เที่ยวในวันเดิม · ผู้จอง ADMIN (สระบุรีแก้เอง) · ช่องที่กลายเป็นซ่อมรถ/พขร.ติดงาน
- % ผิดแผน = รายการที่นับ ÷ จำนวนงานใน Rev 0 (ถ้ายังไม่มี Rev 0 ใช้ฉบับเลขน้อยสุด)
- BU = หน่วยของศูนย์สระบุรีในช่องงาน (CUT&BEND, FORMWORK, FURNITURE, MAINTENANCE, PRECAST, S CRANE, STORE, TECHFORM, FURNITURE ปู่เจ้า) · งานที่ไม่ผ่านศูนย์ = "อื่นๆ (ขนตรง)"

## ไฟล์
- `services/route_plan_pdf.js` — อ่าน PDF ด้วยตำแหน่งตัวหนังสือ (pdfjs) · ถ้าสระบุรีเปลี่ยนหน้าตาตาราง แก้ที่นี่
- `services/route_plan.js` — อัปโหลด, เทียบ Revise, สาเหตุ, รายงาน (ฟังก์ชัน `RPLAN_*` ผ่าน `/api/gas`)
- `routes/route_plan_file.js` — เปิด PDF/ไฟล์แนบ (`/api/route-plan-file/rev|att/:id`, admin)
- `public/route-plan.html`

ทดสอบกับแผนจริงสัปดาห์ 9–15 พ.ย. 2569 (Rev 0–3): อ่านครบ 15 คัน, จับการเปลี่ยนแปลงตรงกับเอกสาร (เช่น Rev 3 ยกเลิก CUT&BEND → 16 RESIDENCES ของ VORASIN ตรงกับใบแจ้งยกเลิก "สั่งซ้ำในระบบ")
