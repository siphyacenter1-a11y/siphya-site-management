# เช็คลิสต์ตาม SITE LAYOUT — การใช้พื้นที่ / การจัดกองวัสดุ + ใบแจ้งแก้ไข

หน้า `/site-layout` · ใช้ได้กับบัญชี **ธุรการ (staff)** และ **admin**

## ติดตั้ง
```
node scripts/migrate_site_layout.js     # สร้างตาราง sl_* (รันซ้ำได้ ไม่ลบข้อมูล)
```
รูปเก็บที่ `public/uploads/site-layout/<ปี-เดือน>/` — ต้องรวมในการสำรองข้อมูลเหมือน uploads อื่น

## ตาราง
| ตาราง | เก็บอะไร |
|---|---|
| `sl_points` | จุดตรวจตาม Layout ของแต่ละโครงการ (A01… / M01… / R01…) + หัวข้อ + เจ้าภาพพื้นที่ |
| `sl_layouts` | รูป Layout ของโครงการ แยกการใช้พื้นที่ / การจัดกองวัสดุ |
| `sl_rounds`, `sl_round_items` | รอบตรวจ + ผล ✓/✗ ของแต่ละจุด |
| `sl_notices` | ใบแจ้งแก้ไข (1 ใบ ต่อ 1 จุดที่ ✗) · รายการที่ผิด · ผู้รับผิดชอบ · กำหนดแก้ · รูป Before/After · ผลตรวจปิดงาน |

## การใช้งาน
1. **ตั้งค่าจุดตรวจ / Layout**: เลือกประเภท + โครงการ → "ใช้จุดตรวจตั้งต้นจากแบบฟอร์ม" → แก้ให้ตรง Layout → บันทึก · อัปโหลดรูป Layout
2. **ตรวจ**: "+ รอบตรวจใหม่" → ติ๊ก ✓/✗ ทุกจุด (ปุ่ม "✓ ทั้งหมด" แล้วค่อยแก้จุดที่ไม่ตรง) → บันทึก
   - จุดที่ ✗ ระบบออกใบแจ้งแก้ไขให้อัตโนมัติ เลขที่ `<โครงการ>-SA|SM<ปีพ.ศ.><เดือน>-<ลำดับ>` เช่น `0DJ-SM6911-001`
   - แก้รอบตรวจภายหลัง: เปลี่ยน ✗ เป็น ✓ → ใบแจ้งที่ยังไม่ได้กรอกอะไรถูกลบ (ใบที่มีข้อมูล/รูปแล้วเก็บไว้)
3. **ใบแจ้งแก้ไข**: กรอกรายการที่ผิด ผู้รับผิดชอบ กำหนดแก้ แนบรูป Before → แก้เสร็จแนบรูป After →
   "ตรวจแล้ว ผ่าน → ปิดงาน" (ต้องมีรูป After) หรือ "ตรวจแล้ว ไม่ผ่าน" (ระบุสิ่งที่ต้องแก้เพิ่ม ใบยังค้าง)
4. พิมพ์เช็คลิสต์ (Layout ซ้าย + ตารางขวา) และใบแจ้งแก้ไข (หน้า + หลังรูป Before/After) จากปุ่มพิมพ์ของแต่ละหน้า

## KPI (แยก 2 ประเภท)
**KPI = (จำนวนครั้งที่เข้าตรวจ ÷ จำนวนครั้งทั้งหมด) × 100**
- จำนวนครั้งทั้งหมด = **4 ครั้ง/เดือน/โครงการ** · เดือนที่ตรวจเกิน 4 นับแค่ 4
- เริ่มนับตั้งแต่เดือนแรกที่โครงการมีรอบตรวจในระบบ (เดือนก่อนเริ่มใช้ระบบไม่นับ)
- แสดงประกอบ (ไม่อยู่ในสูตร): ใบแจ้งที่ออก / ปิดแล้ว / ค้างเกินกำหนด

## สิทธิ์
- ธุรการ: ตรวจ แก้รอบตรวจ ใบแจ้งแก้ไข ปิดงาน ตั้งค่าจุดตรวจ/Layout
- admin: เหมือนธุรการ + ลบรอบตรวจ (ลบใบแจ้งของรอบนั้นด้วย)
