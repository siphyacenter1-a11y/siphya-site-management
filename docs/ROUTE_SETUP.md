# ติดตั้งระบบแผนการเดินรถ (คำขอขนส่งภายนอกไซต์)

หน้า `/route` คือหน้าเดียวกับที่ใช้บน Google Apps Script (ฟอร์มคำขอ ปกติ/ด่วน/ยกเลิก + Dashboard)

```bash
node scripts/migrate_route.js   # ใช้ตาราง vehicle_transport_requests เดิม ถ้ายังไม่มีจะสร้างให้ ไม่ลบข้อมูล
```

- บันทึกลงตาราง `vehicle_transport_requests` ที่มีอยู่ (`doc_type` เก็บเป็น NORMAL / URGENT / CANCEL)
- server ตรวจช่องบังคับ ประเภทเอกสาร รูปแบบเดือน/วันที่ และวันลงของต้องไม่ก่อนวันขึ้นของ
- `/api/route/logs` เดิมยังใช้ได้

ทดสอบแล้วผ่าน 14/14 และทดสอบกรอกฟอร์มจริงในเบราว์เซอร์
